Bonus Entries Quiz (static site)
What this is
A 3-question scavenger-hunt quiz.

Q1 uses weighted random selection (Got Your Six Dispensary weighted highest at 16%).
Q2 uses equal random selection from all 14 clients.
Q3 always uses the same client as Q2.
Search terms randomize per client on each quiz attempt.
Each time a user starts or retries the quiz, they get a fresh random selection with shuffled answer positions.
